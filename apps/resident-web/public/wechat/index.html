Open the WeChat application

邻需通 is a WeChat application. If you use WeChat, this is the recommended way to use it.

Open the real application in WeChat on your phone, either way:

  1. Scan — tap + → Scan and scan the code above. Reading this on your phone? Save the code, then choose it from your photos in the Scan screen.
  2. Search — search 邻需通 in WeChat.

The code opens only in WeChat; an ordinary phone camera cannot open it.
